# Al Hadaf — v6

Cloudflare Worker + D1 + KV দিয়ে চলা জুব্বার অনলাইন শপ।

## v6-এ নতুন যা এসেছে

1. **কাস্টমার লিস্ট (কে কতবার কিনেছে)** — Admin › Customers। প্রতিটি কাস্টমার কতবার কিনেছে, কত টাকা খরচ করেছে, শেষ কবে কিনেছে। গ্রুপ: VIP, ২+ বার কিনেছে, একবার কিনেছে, কাস্টম জুব্বার ক্রেতা, ৯০ দিন কেনেনি, বেশি বাতিল। নিজের ট্যাগ (যেমন "Eid buyer") দিতে পারবেন। নাম চাপলে পুরো ইতিহাস আর কী কী কিনেছে দেখায়।
2. **অফার পাঠানো** — কাস্টমারদের টিক দিয়ে "Send SMS offer"। মেসেজে {name} লিখলে প্রত্যেকের নাম বসে যায়, কুপন কোড এক ক্লিকে যোগ হয়। CSV ডাউনলোড করে Facebook বিজ্ঞাপনেও ব্যবহার করা যায়।
3. **হিরো ব্যানার স্লাইডার** — Admin › Banners থেকে ছবি, লেখা, বাটন দিন। হোম পেজে নিজে নিজে স্লাইড করে।
4. **ফেক অর্ডার ধরা** — প্রতিটি অর্ডারে কাস্টমার আগে কতবার নিয়েছে/বাতিল করেছে দেখায়। "Check customer record" চাপলে সব কুরিয়ারের রেকর্ড (BDCOURIER_API_KEY লাগবে)।
5. **Unfinished orders** — চেকআউটে মোবাইল নম্বর দিয়ে অর্ডার না করলে এখানে আসে, এক ক্লিকে কল বা WhatsApp।
6. **উইশলিস্ট আর সম্প্রতি দেখা পণ্য** — জুব্বায় হার্ট দিলে পছন্দের তালিকায় থাকে।
7. **সার্চ** — উপরে খোঁজার আইকন। নাম, রং, কাপড়, কোড দিয়ে খোঁজে।
8. **বান্ডেল অফার** — Shop info থেকে, যেমন "২টি নিলে ১০% ছাড়"। নিজে থেকেই কার্টে হিসাব হয়।
9. **স্টকে ফিরলে জানানো** — স্টক শেষ সাইজে চাপলে কাস্টমার নম্বর রেখে যায়। স্টক বাড়ালে নিজে থেকেই SMS যায়।
10. **কাস্টমার অ্যাকাউন্ট** — মোবাইল নম্বর + SMS কোড দিয়ে লগইন, আগের অর্ডার, আবার অর্ডার, ঠিকানা সেভ (SMS সেটআপ লাগবে)।
11. **SEO** — প্রতিটি পণ্যের নিজের লিংক (যেমন `/p/AH-1001`), Google আর Facebook শেয়ারে ছবি-দাম দেখায়, `sitemap.xml`। Google Search Console-এ sitemap জমা দিন।
12. **bKash অনলাইন পেমেন্ট** — কাস্টমার bKash পেজে সরাসরি পেমেন্ট করে, Transaction ID লাগে না।

## bKash অনলাইন পেমেন্ট চালু করা

1. bKash-এ মার্চেন্ট অ্যাকাউন্ট খুলে **Payment Gateway (Tokenized Checkout)** চান। ওরা App Key, App Secret, Username, Password দেবে।
2. প্রথমে **sandbox** (টেস্ট) চাবি দিয়ে Cloudflare-এ এই Secret-গুলো দিন: `BKASH_APP_KEY`, `BKASH_APP_SECRET`, `BKASH_USERNAME`, `BKASH_PASSWORD`।
3. চেকআউটে "bKash (pay now)" বেছে টেস্ট করুন। bKash-এর টেস্ট ওয়ালেট: 01770618575, OTP 123456, PIN 12121।
4. ঠিক থাকলে আসল চাবিগুলো দিন আর আরেকটা Secret যোগ করুন: `BKASH_MODE` = `live`।

## কুরিয়ার ফ্রড চেক

bdcourier.com-এ অ্যাকাউন্ট খুলে API key নিন, Cloudflare-এ `BDCOURIER_API_KEY` নামে Secret দিন। শুধু নতুন অর্ডার যাচাইয়ের জন্য ব্যবহার করুন।

## v5-এ যা এসেছিল

1. **অ্যানিমেশন** — হোম পেজের শিরোনাম ধাপে ধাপে আসে, স্ক্রল করলে প্রোডাক্ট কার্ড আর সেকশন ভেসে ওঠে, ছবিতে মাউস রাখলে জুম, কার্টে যোগ করলে কার্ট আইকন লাফায়, কার্ট/চেকআউট স্লাইড করে খোলে। যাদের ফোনে "Reduce motion" চালু, তাদের জন্য অ্যানিমেশন বন্ধ থাকে।
2. **অটোমেটিক অ্যানিমেটেড গ্যালারি** — যত পণ্যের ছবি যোগ করবেন, সব নিজে থেকেই গ্যালারিতে চলে আসে। হোম পেজে দুই সারি ছবি উল্টো দিকে নিজে নিজে স্লাইড করে (মাউস রাখলে থামে)। গ্যালারি পেজে ক্যাটাগরি অনুযায়ী ফিল্টার। ছবিতে ক্লিক করলে বড় হয়, সেখান থেকে পণ্যে যাওয়া যায়।
3. **অর্ডার ডিলিট** — Orders-এ প্রতিটি অর্ডারে "Delete order"। New বা Confirmed অর্ডার মুছলে স্টক ফেরত যায়।
4. **কুপন** — Admin › Coupons। শতাংশ ছাড়, নির্দিষ্ট টাকা ছাড়, বা ফ্রি ডেলিভারি; সর্বনিম্ন অর্ডার, কতবার ব্যবহার, শেষ তারিখ। কাস্টমার চেকআউটে কোড দেয়।
5. **রিভিউ ও রেটিং** — প্রোডাক্ট পেজে স্টার রেটিং আর রিভিউ। Admin › Reviews থেকে Approve করলে তবেই দেখায়। যে নম্বরে ডেলিভারি পেয়েছে সেই নম্বর দিলে "Verified buyer" চিহ্ন।
6. **Facebook Pixel** — Admin › Shop info-তে Pixel ID দিন। PageView, ViewContent, AddToCart, InitiateCheckout, Purchase নিজে থেকেই যায়।
7. **Steadfast কুরিয়ার** — অর্ডারে "Send to Steadfast" ক্লিক করলে পার্সেল বুক হয়, ট্র্যাকিং নম্বর সেভ হয়, অর্ডার Shipped হয়। কাস্টমার Track order পেজে Steadfast লিংক পায়।
8. **SMS** — অর্ডার পেলে, কনফার্ম হলে, পাঠালে, ডেলিভারি হলে কাস্টমারকে SMS (bulksmsbd.net)। কোনটায় যাবে Admin › Shop info থেকে ঠিক করবেন।

## Steadfast চালু করা

1. Steadfast মার্চেন্ট প্যানেল বা সাপোর্ট থেকে **API Key** আর **Secret Key** নিন।
2. Cloudflare › Workers › al-hadaf › Settings › Variables and Secrets › Add (Type: Secret):
   - `STEADFAST_API_KEY`
   - `STEADFAST_SECRET_KEY`
3. Admin › Shop info › Courier-এ "Steadfast connected" দেখালে তৈরি।

## SMS চালু করা (bulksmsbd.net)

1. bulksmsbd.net-এ অ্যাকাউন্ট খুলে ব্যালেন্স রিচার্জ করুন, **API Key** আর **Sender ID** নিন।
2. ওদের ড্যাশবোর্ডে Phone Book › IP White List থেকে IP whitelisting **বন্ধ** করুন (Cloudflare-এর IP বদলায়, তাই এটা জরুরি)।
3. Cloudflare-এ দুটো Secret যোগ করুন: `SMS_API_KEY` আর `SMS_SENDER_ID`।
4. Admin › Shop info › SMS to customers-এ কোন কোন সময়ে SMS যাবে টিক দিয়ে Save করুন।

## v4-এ যা এসেছিল

1. **সোশ্যাল আইকন** — Facebook, Messenger, WhatsApp, Instagram, YouTube, TikTok, Email। Admin › Shop info থেকে লিংক দিলেই footer, মেনু আর Contact পেজে আইকন দেখাবে। খালি রাখলে লুকানো থাকবে।
2. **লাইভ চ্যাট** — ওয়েবসাইটের নিচে ডানে চ্যাট বাটন। কাস্টমারের মেসেজ Admin › Chats-এ আসে, সেখান থেকে উত্তর দেবেন। মেনুতে না-পড়া মেসেজের সংখ্যা দেখায়। চ্যাট কাস্টমারের ফোনে সেভ থাকে।
3. **নিজের মাপে জুব্বা** (`/#/custom`) — কাস্টমার কাপড় → স্টাইল (কলার, হাতা, পকেট, বোতাম) → সাইজ বা নিজের মাপ (ইঞ্চি) বেছে অর্ডার করে। দাম সার্ভারে হিসাব হয়। Admin › Tailoring থেকে কাপড়, অপশন আর দাম বদলাবেন। অর্ডারে পুরো মাপ দেখা যায়।
4. **গ্যালারি** — Admin › Gallery থেকে ছবি আপলোড। হোম পেজে আর `/#/gallery` পেজে দেখায়, ক্লিক করলে বড় হয় (lightbox)। প্রোডাক্ট পেজের ছবিতেও ক্লিক করে বড় দেখা যায়।
5. **প্রফেশনাল অ্যাডমিন** — সাইডবার, Dashboard (আজ/৭ দিন/৩০ দিনের বিক্রি, চার্ট, বেস্ট সেলার, লো স্টক, To do), Customers, অর্ডারে তারিখ ফিল্টার, CSV ডাউনলোড, ইনভয়েস প্রিন্ট, প্রাইভেট নোট।
6. **অর্ডার ট্র্যাক** (`/#/track`) — অর্ডার নম্বর + মোবাইল দিয়ে কাস্টমার নিজেই অবস্থা দেখতে পারে।
7. **Telegram নোটিফিকেশন** (ঐচ্ছিক) — নতুন অর্ডার আর চ্যাট আসলে মোবাইলে মেসেজ।

- রিপোর পুরনো `products.js` আর লাগে না, চাইলে মুছে দিতে পারেন।

## Telegram নোটিফিকেশন চালু করা

1. Telegram-এ **@BotFather** খুলুন, `/newbot` লিখে একটি বট বানান। যে **token** দেবে সেটা কপি করুন।
2. নিজের নতুন বটকে একটা মেসেজ দিন (যেমন "hi")।
3. ব্রাউজারে খুলুন: `https://api.telegram.org/bot<TOKEN>/getUpdates` — সেখানে `"chat":{"id": 123456789` এই সংখ্যাটা আপনার **chat id**।
4. Cloudflare Dashboard › Workers › al-hadaf › Settings › Variables and Secrets › Add:
   - `TELEGRAM_BOT_TOKEN` = টোকেন
   - `TELEGRAM_CHAT_ID` = chat id
5. Save করুন। এখন থেকে নতুন অর্ডার আর চ্যাটের মেসেজ ফোনে আসবে।

## Cloudflare ফ্রি প্ল্যানে চ্যাট

চ্যাট উইন্ডো খোলা থাকলে প্রতি ৪ সেকেন্ডে, বন্ধ থাকলে প্রতি ৪৫ সেকেন্ডে নতুন মেসেজ চেক করে, শুধু যে কাস্টমার চ্যাট শুরু করেছে তার জন্য। ফ্রি প্ল্যানের দিনে ১ লাখ রিকোয়েস্ট ছোট দোকানের জন্য যথেষ্ট।
